# Kaizen Website

An introductory website for Kaizen, built as a fast static site with the same visual identity as the app.

## Local preview

```bash
python3 -m http.server 4173 --directory dist
```

Then open `http://localhost:4173`.

## EdgeOne Pages

Connect this repository and use `dist` as the output directory. No build command is required.
